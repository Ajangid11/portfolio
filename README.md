## Running Locally

```bash
pnpm install
pnpm dev        # http://localhost:3001
```

The contact form posts to [Web3Forms](https://web3forms.com). Set `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY`
in `.env.local` (and in your hosting provider's env settings) or submissions will fail.
